# prototype luweb — ULFS4 Student Portal

A lightweight, student-built web portal for the **Lebanese University — Faculty of Sciences, Branch 4 (ULFS4)** to centralize daily class schedules, Cours/TD/Dawrat, announcements, nearby student spots, and campus forum discussions.

> **Disclaimer:** This is an unofficial student-made website. The official Lebanese University SIS portal is available at [http://sisol.ul.edu.lb/](http://sisol.ul.edu.lb/).

## Features
- **Today Dashboard:** Next-up class card, Quick Jump to core ULFS4 courses, verified announcements, and a Light/Dark theme switch.
- **Daily Calendar:** Flip day-by-day through schedules, filter by major or academic year (`Year 1 / 2 / 3`), search any class, and export `.ics`.
- **Cours:** Bilingual (`English` / `Français`) archive for Mathematics, Physics, and Computer Science (`Cours`, `TD`, `Dawrat`, `Solutions`, `Books`, `Syllabi`).
- **Offers & Near You:** Local food, coffee, printing, and tech spots with price/popularity sorting and tags.
- **Forum:** Student Q&A and discussion feed with upvotes, downvotes, comments, and file attachments.
- **Survival Guides & Bylaws:** Practical guides and site disclaimers.

## Tech Stack
- HTML, CSS, and JavaScript (`index.html`, `styles.css`, `app.js`)
- PostgreSQL schema included (`schema.sql`) for Neon / Cloudflare R2 backend integration (still not set up)
